# Agilex 5 FPGA E-Series 013B Development Kit — BMC Sensor

Platform folder `dk-a5e013bm16aea-omnimc-sensor` contains designs for the Agilex 5 FPGA
E-Series 013B Development Kit DK-A5E013BM16AEA with the BMC sensor daughter card.

Refer to the [Agilex 5 E-Series 013B Development Kit Baseline System Example Design](https://altera-fpga.github.io/latest/embedded-designs/agilex-5/e-series/013B/gsrd/ug-gsrd-agx5e-013b) for Baseline System Example Design context.
