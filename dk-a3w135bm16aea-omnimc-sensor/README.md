# Agilex 3 FPGA and SoC C-Series Development Kit — BMC Sensor

Platform folder `dk-a3w135bm16aea-omnimc-sensor` contains designs for the Agilex 3 FPGA
and SoC C-Series Development Kit DK-A3W135BM16AEA with the BMC sensor daughter card.

Refer to the [HPS Baseline System Example Design User Guide for the Agilex 3 C-Series Development Kit](https://altera-fpga.github.io/latest/embedded-designs/agilex-3/c-series/gsrd/ug-gsrd-agx3) for Baseline System Example Design context.
